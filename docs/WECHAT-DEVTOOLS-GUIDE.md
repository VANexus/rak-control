# 微信开发者工具体验指南

本指南用于在 Windows 上导入并验证 Rak 社团管理小程序的本地演示版本。开发者工具中的模拟数据只保存在本机，不会连接或写入 Rak 服务器。

## 开始前

- 安装 Node.js、pnpm 和微信开发者工具。首次打开开发者工具时按工具提示登录微信账号；不要把开发者工具登录凭证写入项目或发到聊天中。
- 确认项目目录为 `C:\Users\24800\Desktop\小程序\rak-control`。如果你把项目放在其他位置，下面命令和导入路径要换成自己的实际目录。
- 本地演示不需要 Rak 后端、小程序 AppSecret 或 API key。不要在演示中填入生产服务地址或真实社团、成员、财务数据。

## 构建小程序

在 PowerShell 中切换到源码目录，再安装依赖、运行测试并构建：

```powershell
Set-Location 'C:\Users\24800\Desktop\小程序\rak-control'
pnpm install --frozen-lockfile
pnpm test
pnpm build:weapp
```

如果依赖此前已安装，通常不必重复安装。若当前 PowerShell 会话曾用于连接测试 API，先清除会影响模式选择的环境变量，再执行构建：

```powershell
Remove-Item Env:TARO_APP_DEMO -ErrorAction SilentlyContinue
Remove-Item Env:TARO_APP_API_BASE -ErrorAction SilentlyContinue
pnpm build:weapp
```

开发构建默认使用本地演示。构建完成后确认以下两个文件存在：

```powershell
Test-Path .\dist\app.json
Test-Path .\dist\project.config.json
```

两个结果都应为 `True`。`dist` 是微信开发者工具运行的构建产物。项目根目录的 `project.config.json` 已配置 `miniprogramRoot: dist/`；导入 `rak-control` 项目根目录，不要选择 `src` 或 `dist` 子目录。本地订阅提醒云函数已移除，无需配置云开发环境。

## 导入与启动

1. 打开微信开发者工具，在首页选择“导入项目”。
2. 项目目录选择 `C:\Users\24800\Desktop\小程序\rak-control`。项目配置会从 `dist` 加载小程序页面。
3. 项目 AppID 已配置为 `wxa8bf102dcfdcec4c`。若以后更换 AppID，请改源码根目录的 `project.config.json`，重新执行 `pnpm build:weapp` 后再导入项目根目录；不要只改生成文件，避免被下一次构建覆盖。不要借用他人的 AppID。
4. 当前项目配置的 `urlCheck` 为 `false`，这是本地开发工具配置，意味着模拟器不会替你验证请求域名是否合法。演示数据在本地运行，不依赖远程 API；真实 API 联调和发布前，需启用开发者工具的 URL 检查、在微信公众平台配置合法 HTTPS 域名并实际验证，不能把本地演示通过视为域名校验通过。
5. 等待项目编译完成。若没有自动启动，点开发者工具顶部的“编译”。模拟器首次可能短暂显示登录页，随后会进入管理者演示身份。

成功时应能看到 Rak 页面以及“本地演示 · 数据仅保存在当前设备”标识；首页、任务、ROI 和团队页应出现样例内容。若始终停留在无法连接服务器的错误页，说明这次构建可能没有使用演示模式，按“常见问题”中的步骤清理环境变量并重新构建。

## 验证主要流程

1. 在底部导航打开“任务”，切换到“待认领”，选择一个状态为待认领的样例任务，认领并提交完成说明。返回任务列表确认状态已更新。
2. 打开“我的 → 设置”，切换到“管理者”。回到任务页查看待验收任务并通过验收；如需体验驳回链路，可先驳回一个已提交任务，再切回“成员”身份补充说明并重新提交，最后切回管理者验收。
3. 作为管理者打开“团队”及其管理入口，查看成员目录、发布一条公告；回到团队公告列表确认公告显示。
4. 打开“ROI”，查看初始收入与支出统计；通过管理入口新增一条演示收支记录，再返回列表和汇总确认变化。
5. 在“我的 → 设置”依次切换成员、管理者、超级管理员，检查管理入口随演示身份变化。切换后应用会重新进入首页。
6. 需要重新开始时，在“我的 → 设置”选择“恢复演示数据”。这会清除本项目本机存储中的演示修改，并恢复初始样例。

页面入口受当前身份影响。若找不到某个管理入口，先确认身份切换成功；不要把演示身份变化当成服务器权限验证。

## 本地数据与能力边界

本地演示可体验任务发布、认领、提交、驳回重提、验收和归档，成员目录、公告管理、ROI 增改查及统计。修改保存在当前开发者工具项目的本地存储中；重编译通常会保留修改。“恢复演示数据”会重置样例，清理开发者工具缓存也可能清掉演示记录。数据不会同步到其他电脑、手机或服务器。

本地演示不验证真实微信登录、微信身份绑定、Rak 服务端角色与权限、邀请码或小程序码签发、入队申请和审批、跨设备同步及真实财务数据。导入和模拟器流程成功，只能说明小程序构建产物可运行且本地演示服务正常。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| `dist\project.config.json` 不存在 | 回到 `rak-control` 源码目录运行 `pnpm build:weapp`，并检查构建输出中最早出现的错误。 |
| 开发者工具提示找不到页面或资源 | 确认导入的是 `rak-control` 项目根目录；它会从 `dist` 加载页面。重新构建后在工具中点“编译”。 |
| 应用一直显示连接服务器失败，或看不到本地演示标识 | 在构建用的同一个 PowerShell 会话清除 `TARO_APP_DEMO`、`TARO_APP_API_BASE`，重新运行 `pnpm build:weapp`，然后在开发者工具重新编译。 |
| 页面数据与预期不同 | 在“我的 → 设置”恢复演示数据；若仍异常，打开开发者工具 Console，记录第一条错误及当前页面。恢复前需要保留的演示数据应先自行记录，因为恢复操作会清除本机修改。 |

如果问题仍无法复现或定位，请提供开发者工具版本、导入时所选的完整目录、出错页面和 Console 第一条错误。不要提供微信登录凭证、AppSecret、access token 或 API key。
